# Igor Bich — Personal Website

Personal portfolio and professional résumé website for Igor Bich, a senior software engineer based in Highland Park, New Jersey.

The website presents my software engineering experience across government, financial services, and retail, along with independent game-development projects, technical interests, education, and background.

## Pages

- **Home** — introduction and overview
- **Experience** — professional history, earlier technical work, and education
- **Projects** — independent projects and technical toolkit
- **About** — working style, background, and personal interests
- **Print résumé** — traditional two-page résumé format

## Built With

- HTML
- CSS
- No frameworks or build dependencies

The site is designed as a lightweight, responsive collection of static pages suitable for GitHub Pages.
